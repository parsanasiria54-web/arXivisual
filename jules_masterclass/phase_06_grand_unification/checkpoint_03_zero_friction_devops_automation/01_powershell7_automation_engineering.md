# PowerShell 7 Automation Engineering

To support users with executive functioning constraints, we implement Zero-Friction Automation scripts using PowerShell 7.

## Key Scripts
- `Verify-And-Heal-Environment.ps1`: Diagnoses dependencies (Python, Node, uv) and attempts auto-healing (e.g., creating `.env`).
- `Start-ModularStudio.ps1`: One-click startup for backend, frontend, and external services (Ollama).
- `Run-AllMasterclassTests.ps1`: Automated test execution.

These scripts drastically reduce cognitive load for system operators.
