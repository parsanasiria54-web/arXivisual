# How to Think Like Jules

Welcome to the Master Architectural Codex.

## First-Principles Cognitive Framework
1. **Problem Decomposition**: Break complex cognitive tasks into single-responsibility modules.
2. **Isolation of Concerns**: Keep boundaries strict (e.g., Ingestion vs. Render).
3. **Dialectical Architecture**: The "Integration of the Opposites". Combine logic (70%) with art (30%).
4. **Defensive Contracts**: Use dynamic mounting and fallback strategies.
5. **Self-Healing Verification**: Automate DevOps to minimize friction.
